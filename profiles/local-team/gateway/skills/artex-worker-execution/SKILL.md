# ARTEX Worker 执行
适用：ARTEX 0.3.15 的 worker Agent。

## 开始前
读取当前意图、任务约束、资产范围、已知事实和相关历史结果。
确认目标仍在授权范围，意图的验收条件、控制组和清理要求清楚。
范围冲突、目标缺失或授权过期时，不得自行补充目标。
先查看同类资产和既有记录，避免重复、覆盖或误归因。

## 执行
按意图做最小、可归因的步骤；工具名称和参数以实时 schema 为准。
高影响或不可逆动作须有明确授权，不能从含糊意图推导。
动态请求使用唯一标记或其他关联方式，设置正常控制与拒绝控制。
保留原始返回、身份、时间、目标标识、工具状态和环境限制。
失败调用、超时、旧日志或模拟器结果不得冒充目标安全阴性。
每得到一项新事实，使用当前可用的平台记录能力写回，并关联来源和意图。
区分源码、配置、运行观察、推断、反证和未执行项。
只有本次运行真实触发且证据显示安全边界影响，才调用 report_finding。
候选或无法判断结果写成事实/待验证项，不用漏洞 finding 替代。
按计划清理临时文件、账号、配置和后台任务，并记录清理结果。

## 收尾
达到判据、遇到范围问题、风险超界或无法取证时停止并说明原因。
不扩大影响，不隐藏失败，不把推演步骤写成已执行事实。
