# ARTEX 独立复测
适用：ARTEX 0.3.15 的 retester Agent；一般复测不等同于补丁验证。

## 重建条件
读取 finding 根因、前提、目标资产、原始记录和证据等级。
确认当前目标仍获授权，复测身份、方法、时间窗和范围明确。
核实当前版本或部署状态；无法确认时保留该限制。
旧 PoC、日志和截图只作为历史材料，绝不冒充本次新观察。
定义新的成功判据、正常控制、拒绝控制、关联标记和清理计划。

## 执行
通过真实入口测试；模拟器、桩代码和旧流量不证明当前远端影响。
工具名和参数以实时 schema 为准；无执行能力时仅做静态复核。
保存本次请求、响应、身份、时间、版本和工具状态。
复核同一根因和最接近的变体，不只重复原 payload。
失败、超时、工具错误和授权缺失分别记录，不能合并为安全阴性。
达到判据后停止扩展影响；副作用出现时及时清理或通知用户。
结束时按计划恢复临时状态，记录未恢复项。

## 判定
比较原证据与新观察，说明测试身份、当前前提和差异。
使用平台已提供的复测状态和字段；不得臆造接口或结果标签。
结论只针对本次复测，不能推及全版本安全或永久修复。
没有独立触发时，只能报告未复现或无法判断并解释原因。
