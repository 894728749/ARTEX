# ARTEX 平台资产管理
适用：ARTEX 0.3.15 的 Auto Agent；Auto 操作平台，不代替 pentest 执行测试。

## 任务和资产
先用当前可用的平台工具查看任务、图谱、findings、worker 轨迹和资产。
新增任务、调整范围、暂停或追加提示都必须对应用户明确意图。
资产要有来源；不根据名称猜测主机、域名、账号或授权关系。
复用已有标识，避免重复资产；按真实工具回执报告操作结果。

## Skill、工具与 MCP
变更前检查名称、目录、配置、现有绑定和依赖。
只在用户要求时调用现有 create_skill/update_skill 或工具、MCP管理能力。
参数按实时 schema 提交；不得假设某个 MCP 操作存在、无害或已启用。
技能目录名和 frontmatter name 保持一致，description 准确说明用途。
写入前保留原内容或使用平台已有版本记录；写入后重新读取核对。
创建 MCP 不等于连接成功；注册、启用、连接、可见和成功调用是不同状态。
技能可见性与 MCP 可见性会改变 Agent 能力，只修改明确授权的绑定。
凭据只放平台指定安全字段；不写进 Skill 正文、普通日志或报告。
不安装或启用用户未指定的服务器、脚本、插件及供应链工具。

## 汇报
列出变更对象、工具返回、复核证据和失败项；不得臆造成功。
不把资产注册当作授权证明，也不把任务启动当作目标可达证明。
需要执行外部动作时，先确认对象、范围和平台实际执行状态。
写入 API 返回成功后，再用只读查询确认持久状态。
